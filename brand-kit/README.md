# Career Ninja brand kit

Source of truth is code: `src/components/brand.tsx` (mascot + mark) and `src/app/icon.svg` (favicon).
These SVGs are exported from it.

- mochi-*.svg: Mochi the mascot in each mood (happy is the default; searching, thinking, excited, sleeping, sad, surprised, love).
- mark-c.svg: the brush-stroke "c" mark.
- favicon.svg: browser tab icon. `src/app/apple-icon.tsx` renders the iOS icon from the same shapes.
- Wordmark: text "careerninja." in the display font, white with a coral full stop (no image, it is live text).
- minds.svg, animoca.svg: partner logos shown on the landing page.

Colours: coral #c96567, night #141b22, surface #1b2530, cream #f5e6dc, ink #141b22, mouth #9e5a63.
